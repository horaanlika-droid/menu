# Счастье на руках

Свадебное коктейльное меню в форме **полной колоды из 36 карт**: 6–10, J, Q, K, A в каждой из четырёх мастей.

**Веб-версия:** [открыть приложение на GitHub Pages](https://horaanlika-droid.github.io/menu/).

Дизайн основан на **двух исходных референсах в корне репозитория** — `IMG_7256.jpeg` и `IMG_7257.png`. Белые лица, тонкая чёрная рамка, красные/чёрные масти и индексы в противоположных углах. Названия коктейлей набраны Helvetica Bold (с системным Arial/sans-serif как запасным вариантом). Общая бордовая рубашка; светлая версия для экономии краски. Без рисунков бокалов. Имена и дата из фотографий не перенесены: это референсы, а не подтверждённые данные мероприятия.

## Готово к печати

- [`public/koloda-a3.pdf`](public/koloda-a3.pdf) — основная колода с бордовыми рубашками.
- [`public/koloda-a3-light.pdf`](public/koloda-a3-light.pdf) — та же колода со светлыми рубашками.
- [`public/menu-36-kart.md`](public/menu-36-kart.md) — все названия, описания вкуса и интерактивы текстом.

Оба PDF: **4 страницы альбомного А3 (420 × 297 мм)**. Порядок: лица листа 1 → рубашки листа 1 → лица листа 2 → рубашки листа 2. Это **2 физических листа с двусторонней печатью**, не четыре листа.

Печатать **100% / фактический размер**, с переворотом **по короткой стороне**, без «подогнать» и колонтитулов. При печати из браузера включить фоновые цвета/графику. Начать с одного тестового листа, проверить совмещение и направление подачи. Бумага 160–200 г/м² — только при поддержке принтером.

На каждой стороне: 6 × 3 карты по **63 × 88 мм**, межкарточный зазор 3 мм, внешние поля 13,5 мм. Метки находятся вне карт. Общие рубашки и симметричная раскладка не требуют зеркалить содержимое оборота. Внутренняя рамка отступает от реза; скругление рамки не требует фигурной резки самих карт.

## Содержание

**24 напитка:** 3 крашера, 6 фруктовых твистов, 6 газированных, 6 барных классических/авторских вариантов, 3 безалкогольных. **12 интерактивов:** 3 сюрприза и 9 вопросов/маленьких заданий. Все 36 карт разные. Точные пропорции не заданы: гость видит название и вкус, не рецептуру.

Алкогольные основы из запроса: виски на чёрном хлебе, готовая база негрони, подслащённая водка 30%, джин с лемонграссом. Маракуйя, клубника, ваниль, персик, яблоко и цитрусы повторяются, чтобы сократить закупку. Варианты с заменами явно обозначены как твисты: например, Джин-Палома не выдаётся за классическую Палому с текилой. Для Хлебного Олд Фэшн указан ароматический биттер; это единственная опциональная дополнительная бутылка, не новая крепкая база.

30% — крепость исходной водки, **не готовых коктейлей**. Алкогольные карты — 18+. Настойка на хлебе может содержать глютен; фактические аллергены в заготовках уточняет бармен. Сюрпризы не подразумевают скрытого алкоголя или обязательного употребления. Безалкогольные варианты не используют алкогольные базы.

## GitHub Pages

После слияния изменений в `main` GitHub Actions соберёт приложение и развернёт его на [horaanlika-droid.github.io/menu](https://horaanlika-droid.github.io/menu/). Workflow находится в `.github/workflows/pages.yml`; Vite собирает приложение с корректным префиксом `/menu/`, включая локальные PDF и favicon. Для первого запуска в Settings → Pages выберите источник **GitHub Actions**, если он ещё не выбран.

## Приложение

```sh
npm ci
npm run dev
```

Vite слушает `0.0.0.0:5173`; предварительный просмотр допускает проксированные хосты Arena. Все шрифты локальные, внешних API, трекеров и платных сервисов нет.

- Фильтры по категории, просмотр всей колоды, перемешивание порядка карт и выбор случайной карты. Перемешивание меняет только экранный порядок, PDF сохраняет исходную раскладку.
- Карта открывается в доступном диалоге; можно перевернуть, изменить название и описание.
- Изменения и подпись/дата рубашки сохраняются в localStorage данного браузера.
- Экспорт всегда включает все 36 карт, независимо от фильтра.
- Стандартные варианты скачиваются как готовый PDF с векторным текстом. Изменённые колоды собираются в браузере при 300 dpi; пользовательские тексты никуда не отправляются.
- «Печатать» использует тот же физический макет; можно сохранить в PDF с векторным текстом.
- Адаптивная вёрстка, клавиатурная навигация, закрытие по Escape, удержание фокуса в диалоге, поддержка reduced motion.

```sh
npm run build          # production build в dist/, не хранится в Git
npm run preview        # предпросмотр production build
npm test               # полнота колоды, категории, геометрия печати, безопасная загрузка настроек
npm run test:browser   # UI, мобильная ширина, редактирование, PDF, физическая раскладка
npm run export:pdf     # пересобрать PDF и текстовое меню; dev server должен работать
```

Для браузерных тестов используется Chromium из npm (`@sparticuz/chromium`), без загрузок с CDN. На других платформах можно указать `CHROMIUM_PATH=/path/to/chrome`. `APP_URL` переопределяет адрес тестируемого сервера. Снимки тестов пишутся в игнорируемую папку `artifacts/`.

## Структура

- `src/data.js` — все 36 названий, описания, основы, заметки бармену и параметры печати.
- `src/Card.jsx` — лица, рубашки, метки и четыре печатные страницы.
- `src/App.jsx` — просмотр, фильтры, настройки и редактирование.
- `src/styles.css` — экранный дизайн и точные размеры в миллиметрах для печати.
- `src/exportPdf.js` — локальный экспорт пользовательской колоды.
- `scripts/export-pdf.mjs` — сборка исходных PDF с векторным текстом и проверка размеров страниц.

Не менять размеры только в одном месте: CSS печати и `PRINT` в `data.js` должны совпадать. После изменения контента/стилей пересобрать готовые PDF.
